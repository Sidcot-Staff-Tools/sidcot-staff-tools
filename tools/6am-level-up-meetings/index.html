6AM and Level Up

Every meeting picks up where the last one left off.

Each student has one record file for all their 6AM and Level Up meetings. Open it, review last time’s targets, set new ones, then share them on Teams or by email home.

    What the tool does
    
        
    The meeting log records 6AM and Level Up meetings in one file per student, so each meeting starts from the targets set last time. It runs in your browser and sends nothing over the internet.
    
        
    Meeting typeWhoTargets
    
          
    6AMEvery sixth form student, in routine tutor meetingsUp to three
    
          
    Level UpPriority students needing extended intervention, weeklyThree each week
    
        
    
        
    Both use the same form: date, last time’s targets, Target 1 to 3, and notes if applicable. Targets from either type are reviewed at the next meeting, whichever type it is.
    
      
    
      
    Before you start
    
        
      
          
    1. Use Chrome or Edge on a school computer. Other browsers download a new copy on every save instead of updating the file.
      2. 
          
    2. Keep records in the agreed staff-only folder, such as a shared sixth form drive with a folder per tutor group.
      3. 
          
    3. Set up sharing once per computer. Click  and add the pastoral leads’ email addresses for Teams, plus your name and role for signing emails home.
      4. 
        
    
      
    
      
    Creating a new student record
    
        
    Do this once per student, at their first meeting. Check they don’t already have a record first.
    
        
      
          
    1. Click New student record on the home screen.
      2. 
          
    2. In Student and parent/carer details, enter the student’s name and year, the parent/carer name as you’d write it after “Dear”, and their email.
      3. 
          
    3. Record the meeting, then click Save record and choose the student’s folder. Keep the suggested file name.
      4. 
        
    
      
    
      
    Running a meeting
    
        
    Everything is on one page. Work from top to bottom.
    
        
      
          
    1. Choose 6AM or Level Up. It starts with the same type as the last meeting, so check it.
      2. 
          
    2. Check the date and tutor. Both fill in automatically.
      3. 
          
    3. Review last time’s targets. Click Achieved, Partly or Not yet for each. Click Carry forward to copy a target into this meeting’s targets.
      4. 
          
    4. Write Target 1, 2 and 3. Level Up sets three each week; 6AM can use fewer.
      5. 
          
    5. Add notes if applicable. Notes can be shared, so keep them suitable for the student and family.
      6. 
          
    6. Optional: open Staff-only notes and next meeting date for notes that never leave the record.
      7. 
        
    
        
    A good target names the action, the evidence and when it’s due. Instead of “revise Chemistry more”, write “complete and self-mark two 30-minute organic chemistry question sets before Friday, and bring corrections to the next meeting”.
    
      
    
      
    Saving the record
    
        
      
          
    • Click Save record or press Ctrl+S. The first save asks where to put the file; after that it updates the same file.
      • 
          
    • With Autosave ticked, changes save automatically every few seconds once the file has been saved or opened.
      • 
          
    • The top bar shows Unsaved changes, Saving… or Saved with the time.
      • 
          
    • If the browser asks whether the page can edit the file, click Allow.
      • 
        
    
      
    
      
    Sharing on Teams and by email home
    
        
    The Share this meeting panel writes both messages as you type. Nothing is sent until you press Send yourself. Staff-only notes are never included.
    
        
    Teams message
    
        
      
          
    1. Open the Teams message tab. Untick Include notes if needed.
      2. 
          
    2. Click Open in Teams: a chat opens with the pastoral leads, message already typed. Check it and press Send.
      3. 
          
    3. Or click Copy message and paste it into any chat.
      4. 
        
    
        
    Email home
    
        
      
          
    1. Open the Email home tab and read the draft. It starts “Dear…, Today I met with…” and lists the targets.
      2. 
          
    2. Tick Include notes only if they’re suitable for home.
      3. 
          
    3. Click Open in email to start the email in Outlook, or Copy email to paste it yourself. Check the address before sending.
      4. 
        
    
      
    
      
    The next meeting
    
        
      
          
    1. Click the student’s name under Recent records, or Open a student record to find their file.
      2. 
          
    2. Click Allow if the browser asks for permission.
      3. 
          
    3. A new meeting is ready, with last time’s targets listed for review.
      4. 
        
    
        
    The bar chart has one bar per meeting: teal for 6AM, gold for Level Up. Taller means more targets achieved; a dashed outline means not yet reviewed. Click a bar to open that meeting. The meetings list and target tracker are at the bottom of the page.
    
      
    
      
    Printing and corrections
    
        
    Click Print, choose a version, then Print or save as PDF.
    
        
    VersionStaff-only notesUse it for
    
          
    Student and family summaryLeft outGiving to the student or sending home
    
          
    Staff recordIncludedA single meeting for staff files
    
          
    Complete historyIncludedEvery meeting and target, for reviews and referrals
    
        
    
        
    To correct a meeting, click Open beside it in the meetings list, change it and save. Delete is only for meetings recorded by mistake; once saved, it can’t be undone.
    
      
    
      
    Data protection and safeguarding
    
        
      
          
    • Keep record files in the agreed staff-only folder. Never on USB sticks or personal devices.
      • 
          
    • Never email or attach the record file. Share targets with the Teams message, the email home or a printed summary.
      • 
          
    • Write shared notes as if the student might read them.
      • 
          
    • Safeguarding concerns don’t belong in this tool. Report them through the school’s safeguarding system straight away.
      • 
          
    • On shared computers, save and close the tool when you’ve finished.
      • 
        
    
      
    
      
    Troubleshooting
    
        
    ProblemWhat to do
    
          
    Save downloads a new file each timeOpen the tool in Chrome or Edge.
    
          
    “Add the student’s name before saving”Open Student and parent/carer details and enter the name.
    
          
    “Click Save record to allow saving”Click Save record and choose Allow.
    
          
    Student missing from Recent recordsRecent records are kept per computer. Use Open a student record.
    
          
    “That file couldn’t be found”It was moved or renamed. Find it with Open a student record.
    
          
    Open in Teams is greyed outAdd email addresses in Sharing settings, and write at least one target.
    
          
    Open in email does nothingUse Copy email and paste into Outlook.
    
          
    Teams message lost its line breaksUse Copy message and paste instead.
